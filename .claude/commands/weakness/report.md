# 不足分析报告生成

正在生成综合不足分析报告...

## 使用方法

```
/weakness/report [period]
```

### 时间周期 (period)
- `all` - 全部历史（默认）
- `week` - 最近一周
- `month` - 最近一个月
- `quarter` - 最近一个季度

## 报告内容

报告将包含以下部分：

### 执行摘要
- 报告周期
- 生成时间
- 追踪不足总数
- 重复出现数量
- 未改善数量

### 🔴 高频重复问题
- 列出出现频率最高的问题
- 显示出现次数、严重性、趋势
- 说明影响范围

### 📊 类别分布
- 按类别统计不足数量
- 显示占比和优先级均值
- 表格形式呈现

### 📈 趋势分析
- 各类不足的出现频率趋势
- 改善进展统计
- 状态转换情况

### 🎯 改进计划
- 按周分解的改进任务
- 优先级排序
- 预期成果

### 📊 统计图表
- 不足优先级分布（饼图）
- 出现频率分布（柱状图）
- 改善进度趋势（折线图）

### 🔗 相关面试
- 列出相关的面试记录
- 便于回顾和对比

---

请指定时间周期（all/week/month/quarter），或直接按回车生成全部历史报告。
